# iTerm2

Consult the official guide on how to import and export iTerm2 settings: [Move Settings Between Machines](https://gitlab.com/gnachman/iterm2/-/wikis/Move-Settings-Between-Machines).

The official method is to load the `.plist` file, but a `Profiles.json` file is also saved as a backup.

### Solarized Dark Patched
This patch allows you to properly view Mocha and Playwright error messages, which are otherwise faded. For this color scheme to display correctly in Vim, you will need to have Solarized8 installed.
